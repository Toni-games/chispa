# Cubiverso Launcher

Programa para Windows al estilo del launcher de Minecraft: eliges la versión de Cubiverso (desde la 1.0 hasta la última), se descarga y juegas con tu cuenta. El progreso es el mismo en todas las versiones.

- La lista de versiones está en `cubiverso/versiones.json` (rama `main`, publicada en GitHub Pages).
- Cada versión es un `.zip` del juego en la carpeta `cubiverso-versiones/` de la rama `main` (GitHub Pages).
