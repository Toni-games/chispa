# Cubiverso para Android

Plataforma de juegos hecha en HTML, como aplicación de Android: avatar, catálogo, Cubos, pases y multijugador con amigos.

## Descargar
Ve a **Releases** (a la derecha en esta página), abre la última versión de Cubiverso y descarga **Cubiverso.apk** en tu móvil o tablet.

Para instalarla, abre el archivo. Si Android lo pide, permite «Instalar aplicaciones de origen desconocido» para tu navegador.

## Cómo se crea
Cada vez que se sube un cambio a la rama `cubiverso-apk`, GitHub crea la APK solo (pestaña **Actions**).
La plataforma está en `app/src/main/assets/cubiverso` y los juegos en `app/src/main/assets/cubiverso/juegos`.
