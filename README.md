# BahíaOS para Android

Escritorio estilo Mac hecho en HTML, como aplicación de Android.

## Descargar
Ve a **Releases** (a la derecha en esta página), abre la última versión y descarga **BahiaOS.apk** en tu móvil o tablet.

Para instalarla, abre el archivo. Si Android lo pide, permite «Instalar aplicaciones de origen desconocido» para tu navegador.

## Cómo se crea
Cada vez que se sube un cambio, GitHub crea la APK solo (pestaña **Actions**).
El sistema está en `app/src/main/assets/bahia` y los juegos en `app/src/main/assets/bahia/juegos`.
